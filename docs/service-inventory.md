### How to fetch OpenAPI from running services (local)

1. Start services (recommended non-Docker local dev): from repo root with venv created:

```bash
cd /Users/matthewng/Desktop/syntrak-application
python3 -m venv .venv   # if not already created
.venv/bin/pip install -r backend/requirements.txt
cd backend && ../.venv/bin/python run.py --all
```

2. When services are running, fetch OpenAPI JSON (many FastAPI apps expose `/openapi.json` or `/docs`):

```bash
curl -sS http://localhost:8080/openapi.json -o openapi-main.json
curl -sS http://localhost:5001/openapi.json -o openapi-community.json
curl -sS http://localhost:5100/openapi.json -o openapi-activity.json
curl -sS http://localhost:5200/openapi.json -o openapi-map.json
```

3. Place extracted specs under `packages/shared/openapi/` (one file per service) and add to the repo. These become canonical API contracts for frontend and CI checks.
